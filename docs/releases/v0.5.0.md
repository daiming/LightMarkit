# LightMarkit v0.5.0

## 版本说明

LightMarkit v0.5.0 为预览带来整体彩色主题与代码语法高亮，新增 Mermaid 图表全窗口无损放大查看器，并修复多项影响日常使用的缺陷。同时项目仓库迁移至 `daiming/LightMarkit`，应用内项目主页与自动更新地址已同步切换。

## 新增

- 双击标题栏空白区域可最大化或还原窗口。
- 打开 Markdown 文件后默认进入预览模式（各 Tab 记忆自己的视图模式，空白新文档仍默认编辑模式）。
- 预览代码块支持语法高亮（highlight.js，覆盖约 35 种常用语言），配色与编辑器保持一致；未识别语言回退纯文本，且着色不会写回 Markdown 源文件。
- 预览整体彩色主题：标题分级着色，引用块、表头、行内代码采用与编辑器统一的色板；导出 HTML/PDF 与预览配色一致。
- 双击 Mermaid 图表可打开全窗口查看器无损放大查看：SVG 按布局尺寸重新栅格化实现矢量级清晰缩放，支持滚轮缩放、拖拽平移、适应窗口/100% 切换，ESC 或关闭按钮退出。

## 改进

- 预览中代码块与行内代码的字号由正文的 85% 提升到与正文一致，导出 HTML/PDF 同步调整。
- 编辑/预览切换入口从内容区右上角移至标题栏设置按钮之后，快捷键由 `Ctrl+/`（macOS `⌘/`）调整为 `Ctrl+E`（macOS `⌘E`），macOS 原生菜单加速器同步更新。

## 修复

- 修复编辑模式下输入任意字符导致编辑器滚动条跳回顶部并伴随界面闪烁的问题：滚动位置恢复逻辑此前错误地在每次内容变化时触发，现仅在切换 Tab 或切换视图模式时执行。
- 修复先打开文件再打开其所在文件夹后，点击文件树中的同一文件会新建重复 Tab、无法切回对应文档预览的问题：Windows 上目录扫描返回的 `\\?\` 前缀路径已统一还原为与文件对话框一致的普通形式。
- 修复文件加载尚在进行时切换 Tab 会被在途加载抢占激活的问题（表现为打开 3 个文件后点击倒数第二个 Tab 会自动跳到最后一个 Tab）：用户主动切换、新建或关闭 Tab 时作废在途的文件加载请求。
- 修复图表查看器缩放模糊（transform 缩放放大位图）与工具栏被交互舞台遮挡无法点击的问题。

## 构建与下载

- Windows x64：NSIS `.exe`、更新签名和 `latest.json`。
- macOS Intel / Apple Silicon：Universal `.dmg`、Universal `.app.tar.gz` 和更新签名。
- macOS DMG 未使用 Apple Developer ID 签名或公证，首次打开时可能出现 Gatekeeper 提示。
