# LightMarkit v0.6.0

## 版本说明

LightMarkit v0.6.0 重点修复了多文档切换时文件内容串写的严重缺陷，并以同批强化了文件保存的可靠性校验；文件树改用彩色图标并大幅优化目录与文件的视觉区分；同时显著缓解多文档切换卡顿，Mermaid 图表的配色与布局也与应用主题全面统一。

## 新增

- 文件树使用彩色图标区分目录与文件：目录为琥珀色文件夹，随开合切换「打开（盖子 + 托盘双层）/关闭（经典实心）」两种造型，与展开箭头构成双重状态反馈；文件为带内容行的文档造型，颜色随选中态变化（未选中中灰、选中切换主题蓝）。
- 目录标题与文件标题采用字号、字重、明暗三重对比（16px/加粗/近黑 vs 14px/常规/中灰），扫视即可分辨层级。
- 选中文件以浅蓝底 + 蓝色标题 + 左侧深蓝竖条标识，与悬停态明确区分；行高亮为通栏直角扁平样式。

## 改进

- 显著缓解多文档切换卡顿：点击文件树中已打开的文件不再重新读取磁盘；预览渲染结果与本地图片增加 LRU 缓存，切回已看过的文档接近瞬时；编辑器懒挂载，文档首次进入编辑模式才创建 CodeMirror 实例，纯阅读不再初始化编辑器，内存占用更低。
- Mermaid 图表整体配色与应用 Markdown 主题色板统一：矩形节点采用表头蓝系，分组框采用引用块同款风格（浅紫白底 + 紫边），分支色对应标题分级色板。
- Mermaid 布局优化：修复 subgraph 内流程横向铺开的问题（分组内流程恢复自上而下展开），多分组横向并排成列；直角矩形节点改为圆角；横向流程图自动改写为纵向；图适配容器宽度不出现横向滚动条。
- 文件树图标按图形边界裁剪绘制，边缘锐利不发虚。

## 修复

- 修复多文档切换时文件内容串写的严重问题：外部文件变更事件在切换文档的窗口期到达时，守卫使用了过期的闭包状态并跨 Tab 混比，旧文档的磁盘内容会被写进新激活的文档，后续任意一次输入即把 A 文档内容物理写入 B 文档（阅读状态下快速切换文档即可触发）。
- 严格校验修改状态：未修改任何内容时绝不写盘，不再无意义刷新文件时间戳。
- 修复自动保存后 Tab 脏点不消失、切走再切回已保存文档重复写盘的问题。
- 修复编辑器回调闭包过期导致隐藏 Tab 内容可能写进当前激活 Tab 的隐患。

## 构建与下载

- Windows x64：NSIS `.exe`、更新签名和 `latest.json`。
- macOS Intel / Apple Silicon：Universal `.dmg`、Universal `.app.tar.gz` 和更新签名。
- macOS DMG 未使用 Apple Developer ID 签名或公证，首次打开时可能出现 Gatekeeper 提示。
